# 数学模型详述

本文档详细说明了主项目 README 中所述的动力学方程、符号定义和参数取值。

## 1. 坐标系与变量定义
系统采用以下坐标系：
- **空间固定系 (O-XYZ)**：Z 轴竖直向上，O 为支点。

**变量**：
| 符号 | 描述 | 备注 |
| :--- | :--- | :--- |
| `θ (theta)` | 章动角 | 自转轴与 Z 轴的夹角 |
| `φ (phi)`   | 进动角 | 自转轴在 XY 平面投影与 X 轴的夹角 |
| `ψ (psi)`   | 自转角 | 绕对称轴转过的角度 |
| `ω₁`        | 自转角速度 | `ω₁ = dψ/dt` |
| `ω₂`        | 章动角速度 | `ω₂ = dθ/dt` |
| `ω₃`        | 进动角速度 | `ω₃ = dφ/dt` |

## 2. 核心动力学方程
以下三个方程构成了求解系统的闭合方程组。

### 方程 (1)：绕对称轴方向
\[
J \alpha_1 \sin\theta + J \omega_1 \omega_2 \cos\theta - \frac{1}{2} J_c \alpha_3 \sin 2\theta - J_c \omega_2 \omega_3 \cos 2\theta - J_c \omega_2 \omega_3 = 0
\]

### 方程 (2)：章动方向
\[
J \omega_1 \omega_3 \sin\theta - \frac{1}{2} J_c \omega_3^2 \sin 2\theta + J_c \alpha_2 = mgr_c \sin\theta
\]

### 方程 (3)：进动方向
\[
J \alpha_1 \cos\theta - J \omega_1 \omega_2 \sin\theta + J_c \alpha_3 \sin^2\theta + J_c \omega_2 \omega_3 \sin 2\theta = 0
\]

其中，`α₁ = dω₁/dt`, `α₂ = dω₂/dt`, `α₃ = dω₃/dt`。

## 3. 物理参数与初始条件（默认值）
| 参数 | 符号 | 值 | 单位 |
| :--- | :--- | :--- | :--- |
| 绕自转轴转动惯量 | `J` | 0.002 | kg·m² |
| 等效耦合惯量 | `J_c` | 0.0032 | kg·m² |
| 质量 | `m` | 0.5 | kg |
| 质心到支点距离 | `r_c` | 0.08 | m |
| 重力加速度 | `g` | 9.81 | m/s² |

**初始条件**：
- 初始章动角：`θ₀ = 0.5 rad` (~30°)
- 初始进动角：`φ₀ = 0.0 rad` (~0°)
- 初始自转角：`ψ₀= 0.0 rad` (~0°)
- 初始自转角速度：`ω₁₀ = 50.0 rad/s`
- 初始章动角速度：`ω₂₀ = 0.0 rad/s`
- 初始进动角速度：`ω₃₀ = 2.0 rad/s`

## 4. 能量计算
总机械能 `E = T + V`，其中：
- **动能 T**：
  \[
  T = \underbrace{\frac{1}{2} m r_c^2 (\omega_2^2 + \omega_3^2 \sin^2\theta)}_{\text{质心平动}} + \underbrace{\frac{1}{2} J \omega_1^2}_{\text{绕质心自转}}
  \]
- **势能 V**：
  \[
  V = mgr_c (\cos\theta)
  \]
  （势能零点设在 `θ = 90°` 处）

数值验证表明，在仿真过程中 `ΔE/E₀ < 1e-8`。
